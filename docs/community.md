# Community

## Discord

[Join the Discord server](https://discord.gg/DENDVuWq5t) to:

- **Get help** with scripting and CONTROL.
- **Share** your modules and scripts.
- **Package a module**: ask there to have your project packaged as a `.module` file for distribution.
- **Follow releases**: new versions and their SHA-256 hashes are announced there.

Feedback and shared modules are welcome.

## YouTube

[The YouTube channel](https://www.youtube.com/channel/UCUW6Vl6RPbAJfej4yb7Gnuw) has CONTROL videos, updates and walkthroughs.

## VS Code Extension

The [aoe2-control-lua](https://marketplace.visualstudio.com/items?itemName=BigJohn.aoe2-control-lua) extension for Visual Studio Code adds CONTROL's Lua API definitions and code snippets. Install the [Lua Language Server](https://marketplace.visualstudio.com/items?itemName=sumneko.lua) extension as well to get autocompletion from those definitions.
